# Автовыгрузка: настройка (один раз, ~15 минут)

Как работает: скрипт Google Apps Script читает таблицу чатов и таблицу эфиров, заменяет всех людей никами (Паулетта, Хуанито…) и отдаёт по ссылке только ники, зубы и короткие фразы. Каждый час GitHub забирает эти данные, проверяет и обновляет `data/live.json`. Если Google не ответил или прислал что-то странное, на сайте остаются прошлые данные.

Готовая к вставке копия скрипта, с уже вписанными ID таблиц и солью, лежит у вас на компьютере: `private/live.gs`. В репозиторий она не попадает. В репозитории лежит `apps_script/live.gs` с заглушками.

## 1. Создать скрипт в Google
1. Откройте https://script.google.com под аккаунтом, у которого есть доступ к обеим таблицам, и нажмите **Новый проект**.
2. Назовите проект, например «psylive — живая страница».
3. Сотрите всё в `Код.gs` и вставьте содержимое `private/live.gs`. Сохраните (⌘S).

## 2. Проверить
1. Вверху выберите функцию **testLive** и нажмите **Выполнить**.
2. Google попросит доступ к таблицам: **Предоставить доступ** → свой аккаунт → «Приложение не проверено» → **Дополнительно** → **Перейти к проекту**.
3. В журнале будут цифры и первые пять ников с зубами. Настоящих имён там быть не должно.

## 3. Опубликовать как веб-приложение
1. **Начать развертывание → Новое развертывание** → шестерёнка → **Веб-приложение**.
2. **Запуск от имени**: «Я». **У кого есть доступ**: «Все».
3. **Начать развертывание**, скопируйте **URL веб-приложения** (заканчивается на `/exec`).

По ссылке отдаётся то же, что и так видно на сайте: ники и фразы. Ссылку всё равно никуда не публикуйте.

## 4. Отдать ссылку GitHub
Репозиторий → **Settings → Secrets and variables → Actions → New repository secret**. Name: `LIVE_URL`, Secret: скопированный URL.

## 5. Первый запуск
**Actions → Обновить живую страницу → Run workflow**. Через пару минут: зелёная галочка и коммит «Обновить живую страницу».

## Точка Б: как писать в чат
После эфира тренер пишет в любой из чатов сообщение с тегом `#точкаБ`, по строке на человека: ник Telegram, тире или двоеточие, фраза.

```
#точкаБ после эфира 21.11
@ник_студента — маме: Мама, хватит меня успокаивать. Я злюсь, и это нормально.
@другой_ник (альфа-жертва): Я не буду молчать, когда мне неприятно!
@третий_ник: Я имею право злиться.
```

Кому сказана фраза (папе, маме, альфа-жертве, дракону, мужу, свекрови…) пишется после ника: «— маме:» или «(мама)». На странице этот адресат выходит грустнолицым человечком с подписью, и студент говорит фразу ему. Если в фразе есть «!» или мат, лицо злое, иначе грустное. Без адресата грустнолицый выходит без подписи.

- Учитываются только сообщения тренеров (роль «тренер» в листе «Чемпионат_лог»), чтобы никто не вписал фразу за другого.
- Человек должен хоть раз написать в «Исцелении отношений»: по его нику скрипт находит его человечка.
- Чужие имена посреди фразы («…скажу Диме…») не пройдут фильтр. Пишите «папа», «мама», «муж», «подруга».
- На странице эти фразы показываются в жёлтом бабле с подписью «точка Б».

## Прозвища: если человек не нашёлся
В эфирах и отчётах люди бывают записаны прозвищами («янка панамка»), которых в чате нет. Скрипт не угадывает их, а берёт из словаря:
1. В проекте Apps Script нажмите **+ → Скрипт**, назовите файл «Прозвища».
2. Вставьте `private/aliases.gs` (шаблон в репозитории: `apps_script/aliases.example.gs`) и впишите справа `'@ник_в_telegram'`.
3. Сохраните, запустите **debugLive**: список ненайденных станет короче. Обновите развёртывание.

## Фамилии и личное во фразах
Фраза не попадает на площадку, если в ней есть:
- имя или фамилия любого автора чатов или человека из листа «СР_Статистика» (в любом падеже);
- слово из списка `HIDE` в файле «Прозвища» — сюда вписывайте фамилии, которых нет в таблицах;
- слово с заглавной буквы на типичное окончание фамилии (-ов, -ева, -ина, -ский, -енко, -ук…);
- адрес, телефон, номер карты, банк, паспорт, почта; ссылки и @ники.

## Что откуда берётся
- **Человечки**: все, кто писал в «Исцелении отношений», плюс все из таблицы эфиров. Текущие: записаны на эфир в этом месяце, писали в чат за 30 дней, или тренеры. Остальные стоят на дальнем плане.
- **Зубы**: отчёты ЗКФ со строкой «Клиент: … | Зуб: 47».
- **Фразы из чата**: за 180 дней, только с матом или восклицанием, 6–110 знаков, без ссылок, @ников и чужих имён.
- **Перепалки**: двое отвечают друг другу по очереди, не дольше 5 минут между репликами.
- **Бот**: сообщения авторов с «бот» или «Джузеппе» в имени.
- **Ники**: зависят от соли в скрипте. Пока соль та же, ники не меняются. Новый человек получает свободный ник.

## Если что-то поменялось
- **Изменили код скрипта**: **Развертывание → Управление развертываниями → ✏️ → Версия: новая → Развернуть**. Ссылка остаётся прежней.
- **Задача на GitHub красная**: в логе написано, какая проверка не прошла. Имён в логе нет.
- **Ник не нравится**: уберите его из списка `POOLS` в обоих файлах (`private/live.gs` и `apps_script/live.gs`).
