# psylive — «Психостоматология вживую»

Первая страница платформы: наверху 32 кликабельных зуба, под ними человечки-участники с никами вместо имён. Они ходят, говорят фразами из чатов психостоматологии и фразами своей «точки Б», иногда ругаются друг с другом. Нажмите на зуб, чтобы собрать тех, кто с ним работает. Старые студенты стоят на дальнем плане.

## Файлы
- `index.html` — вся страница, 5 вариантов оформления (`#v1`…`#v5`).
- `data/live.json` — данные: ники, пол для цвета, зубы, текущий или старый, фразы, точки Б, перепалки, реплики бота. Настоящих имён и ников Telegram здесь нет. Нет файла — страница показывает демо.
- `apps_script/live.gs` — скрипт Google, который собирает эти данные из таблиц. Настройка: [apps_script/README.md](apps_script/README.md).
- `scripts/fetch_live.py` — забирает данные и строго проверяет: ник только из списка, зубы только FDI, фразы без ссылок и @ников.
- `.github/workflows/update-live.yml` — запуск каждый час.

## Проверить логику без Google
```bash
node test/run.js > /tmp/out.json && python3 scripts/fetch_live.py --file /tmp/out.json --out /tmp/live.json
```
`test/fixture.json` — выдуманные люди и сообщения.

## Правило: никаких настоящих имён
- `.names.local` (не коммитится): имена участников, по одному на строку.
- `python3 scripts/check_no_names.py` проверяет файлы; хук `.githooks/pre-commit` проверяет каждый коммит. Включить: `git config core.hooksPath .githooks`.
